# 📚 TMA - Textbook Management Application (Frontend)

This is the frontend of the **Textbook Management Application** built using Angular. It allows instructors and employees to manage textbooks, inventory, and course-related resources.

## 📦 Tech Stack

- Angular 18
- TypeScript
- SCSS/CSS
- REST APIs (connected to Node.js + PostgreSQL backend)

## 🧰 Features

- Instructor & Sec Employee login
- View and request textbooks
- Inventory management
- Secure API integration
- Role-based dashboard and features

## 🛠️ Getting Started

Follow the steps below to clone and run this project on your local machine.

### Prerequisites

- Node.js (v16+)
- Angular CLI
- Git

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Fahad-12345/TMA_front_end_repository.git

# 2. Navigate to the project directory
cd TMA_front_end_repository

# 3. Install dependencies
npm install

# 4. Run the Angular app
ng serve
